  HCI Tool version 2.0.0.1 - Release Notes
~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~
HCI Tool fix to support ibtusb/ibtpci in operatation mode without debuginterface.

The HCI Tool need to be launched in Administrative console to be able to send vendor specific commands.

Usage :
hcitool.exe [option]

 [options]:
     -v        Print Hci Tool version

     -h        Print help/usage guide

  Bluetooth driver in operational Mode:
     -c <Command string>    Send VS hci commands to controller
               eg: Read intel firmware version command, 'hcitool.exe -c 05FC00'

     -ledon    Turn on BT LED

     -ledoff   Turn off BT LED

  Bluetooth driver in test Mode:
     rdbdaddr  Read Bluetooth device address in Test mode.
               eg: Read bluetooth device Address command, 'hcitool.exe rdbdaddr'
