## Bluetooth I2S Clock Source BIOS Check (hcitool)
 
### Overview
This module provides a Windows-based Bluetooth BIOS configuration check by running:
 
`hcitool.exe -c 8CFC022102`
 
It is designed to be integrated into AI-agent or web-chat workflows so users can trigger the check and receive parsed results directly in the chat UI.
 
### Utility Executable Location
The implementation expects the hcitool executable at the following project-relative path:
 
`Utilities/hcitool/x64/hcitool.exe`
 
In code, the path is resolved relative to the Python module directory with `os.path.join(...)`, so keep the same folder structure when reusing this feature in another project.
 
### What It Checks
The command response is parsed and the **23rd byte** (1-based index) is interpreted as:
 
- `84`: Bluetooth drives I2S clock for HFP (error config)
- `87`: Audio DSP drives I2S clock for HFP (correct config)
- Others: Unexpected config
 
If no valid response bytes are found, return:
 
`hcitool execution fail.`
 
### Admin Execution Design
`hcitool.exe` is executed with an **admin-first** strategy:
 
1. If the current process is already elevated, run directly.
2. If not elevated, execute via PowerShell `RunAs` automatically.
 
For elevated runs, stdout/stderr/exit code are captured using temporary files to ensure output is preserved even when running under UAC.
 
### Core Functions
- `is_admin()`
  - Checks whether current process has administrator privileges.
- `run_with_elevated_privileges(command, timeout=120)`
  - Runs command using PowerShell `RunAs`, captures stdout/stderr/exit code.
- `run_hcitool_command(command, timeout=120)`
  - Admin-first command entrypoint (direct if admin, otherwise elevated run).
- `check_bluetooth_i2s_clock_source_config()`
  - Runs `hcitool.exe -c 8CFC022102`
  - Parses response bytes
  - Evaluates 23rd byte and returns structured result.
 
### Returned Result (Typical)
On success:
- `status`: `success`
- `command`
- `return_code`
- `stdout`
- `stderr`
- `response_bytes`
- `byte_23`
- `config_status` (`correct` / `error` / `unexpected`)
- `description`
- `is_expected_config`
- `is_correct_config`
- `admin_mode` (`already_admin` / `elevated_runas`)
 
On failure:
- `status`: `error`
- `error`
- `command`
- `config_status`: `unknown`
- `byte_23`: `None`
- optional diagnostics: `stdout`, `stderr`, `admin_mode`
 
### Agent Integration (Optional)
Expose the check as a tool via:
 
- `HCITOOL_TOOL_FUNCTIONS`
- `HCITOOL_ANTHROPIC_TOOLS`
 
This allows the AI agent to invoke the check and return parsed BIOS config results directly in chat.
 
### Reuse Checklist for Other Projects
1. Copy the module file.
2. Copy `hcitool.exe` and keep this exact relative location:
   - `Utilities/hcitool/x64/hcitool.exe`
3. Ensure Windows environment supports UAC prompt for elevation.
4. Call `check_bluetooth_i2s_clock_source_config()` from your API/chat route.
5. Render `stdout`, `byte_23`, and `config_status` in your UI response.
